# Task

Detect whether news article text is generated by a human or machine (AI). Binary classification task to identify AI-generated news articles.

# Metric

accuracy

# Submission Format

```
label
human
machine
etc.
```

# Dataset

train.csv
Contains news article text samples with id, text, and label columns.
Labels: 'human' (human-written) or 'machine' (AI-generated).
Balanced dataset with 5,000 samples per class.

test.csv
Contains test samples with id and text columns only (no labels).
2,000 samples for prediction.

test_targets.csv
Contains the true labels for test.csv.
Use this for validation only, not for training.

test_unlabeled.csv
Contains unlabeled test samples with id and text columns only.
Use this for final submission predictions.
